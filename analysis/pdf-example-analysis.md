# Анализ примера бизнес-процесса из PDF

## Общая структура диаграммы

### Ориентация и layout
- **Вертикальная ориентация** - процесс идёт сверху вниз
- **Swimlane по ролям** - вертикальные колонки, каждая роль имеет свою дорожку
- **Пастельные цвета** для каждой дорожки (голубой, розовый, зелёный, жёлтый, сиреневый и т.д.)

### Типы блоков (из наблюдения)
1. **Запуск** - зелёная пилюля/овал в начале процесса
2. **Действие** - шестиугольник (серый/белый)
3. **Продукт/Результат** - скруглённый прямоугольник
4. **Завершение** - прямоугольник с двойными линиями
5. **Разделение** - перевёрнутый треугольник для параллельных веток
6. **Условие/ИЛИ** - маркер с "?" для ветвлений

### Параметры действия (плашки рядом с блоками)
- **Время** - жёлтая плашка с иконкой ⏱
- **Документ** - лист с волнистым низом 📄
- **БД/Система** - цилиндр 🗄
- **Этап** - синяя трапеция

### Связи между блоками
- **Ортогональные стрелки** - только под углом 90°
- **Горизонтальные связи** между дорожками
- **Вертикальные связи** внутри дорожки
- **Пунктирные линии** для параметров и чек-листов

### Особенности визуализации
- Блоки компактные, но читаемые
- Много параллельных веток
- Горизонтальные переходы между ролями
- Этапы процесса выделены цветными полосами сверху
- Нумерация шагов

## Ключевые отличия от текущей реализации
1. Более компактные блоки
2. Больше параллельных веток
3. Горизонтальные связи между дорожками более выражены
4. Параметры (время, документы, системы) отображаются как отдельные плашки рядом с блоками
5. Этапы процесса (фазы) показаны как горизонтальные полосы сверху
